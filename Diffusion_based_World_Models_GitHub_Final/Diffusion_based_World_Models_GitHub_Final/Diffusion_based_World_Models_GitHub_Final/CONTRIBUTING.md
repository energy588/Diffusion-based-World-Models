
# Contributing

Thank you for your interest in improving this repository.

## You can help by
- adding new papers,
- correcting metadata,
- supplementing code or project links,
- refining tags and categorization,
- improving dataset and benchmark summaries.

## Suggested format
```markdown
- **Paper Title** | Venue / Year | [Paper](link) | [Code](link) | Tags: `Driving`, `Embodied`, `World Model`
```

## Pull Request Checklist
- Keep formatting consistent.
- Check links if possible.
- Prefer concise and informative tags.
- Avoid duplicate entries.
