
# Autonomous Driving

Diffusion-based world models for autonomous driving focus on controllable traffic simulation, future scene generation, occupancy / BEV modeling, and closed-loop planning.

## Key Directions
- Multi-view driving video generation
- Trajectory-conditioned future simulation
- Occupancy / BEV world modeling
- Long-tail and safety-critical scenario synthesis
- Closed-loop planning with imagined futures

## Representative Topics
- DriveDreamer / DriveDreamer-2 style frameworks
- GAIA / Vista style driving world models
- BEV / occupancy based future generation
- Planning-oriented driving simulators
